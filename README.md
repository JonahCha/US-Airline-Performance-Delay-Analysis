# US Airline Performance: Delays and Cancellations (2015)

An analysis of on-time performance, cancellation causes, and monthly trends for US airlines, built on the 2015 US Department of Transportation flight data. The pipeline cleans and merges the data, computes the metrics, and produces the charts below. A Power BI dashboard was built from the same data.

## Dashboard

![Airline performance dashboard](docs/images/dashboard.jpg)

The Power BI dashboard above was built earlier from the same 2015 data. Its headline figures did not match a re-run of the data, so the verified results are given below, followed by the comparison.

Full write-up: [docs/Report_Of_Airlines.pdf](docs/Report_Of_Airlines.pdf).

Charts: `docs/images/cancellation_reasons.png`, `docs/images/ontime_by_airline.png`, `docs/images/monthly_cancellations.png`.

To reproduce, download the flights data as described in [data/README.md](data/README.md), then run:

```
python airline_analysis.py --flights data/flights.csv --outdir docs
```

On-time means arriving within 15 minutes of schedule, the FAA definition. The rate uses operated flights only, which excludes cancellations.

## What the pipeline does

1. **Load** flights, airlines and airports.
2. **Clean.** Blank delay-reason fields are set to 0. A `FLIGHT_DATE` column is built from year, month and day.
3. **Merge.** Airline names are joined on the carrier code. Origin and destination airport details are joined separately, with `ORIGIN_INFO_` and `DEST_INFO_` prefixes.
4. **Summarise.** Cancellations and their causes, on-time rates by airline, mean arrival delay, and monthly cancellations.
5. **Report.** Writes `results.txt` and the three charts.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Get the flights data as described in [data/README.md](data/README.md), and save it as `data/flights.csv`. The file is about 560 MB and isn't stored in the repo.

## Tests

```bash
pip install -r requirements-dev.txt
pytest
```

The tests use small synthetic datasets, so they run without the flights file. CI runs them on every push.

## Notes

- The flights file is read in 500,000-row chunks and summarised as it goes, so the full dataset runs on a machine with about 4 GB of memory.
- The original work was a Jupyter notebook with hardcoded Windows paths. It has been replaced by `airline_analysis.py`, which takes file paths as options.
- The Power BI file (`.pbix`) isn't included. The charts in this repo reproduce the main analysis without it.
- The cleaning step now keeps origin and destination airport details separate. The notebook's default merge suffixes mixed them up.
